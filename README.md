# 🖐️ Manos Que Hablan

**Manos Que Hablan** es una aplicación web diseñada para enseñar el **Lenguaje de Señas Colombiano (LSC)** de forma accesible, interactiva y amigable para todos los usuarios en Colombia.

Este proyecto busca promover la inclusión y el aprendizaje del lenguaje de señas mediante herramientas digitales modernas.

---

## 🎯 Objetivo

Desarrollar una plataforma web que permita a los usuarios:

- Aprender el lenguaje de señas colombiano desde cero
- Practicar mediante interacción con la cámara
- Acceder a tutoriales visuales y educativos
- Facilitar la inclusión de personas sordas en la sociedad

---

## 🧩 Funcionalidades (Prototipo)

### 🔐 1. Sistema de Login

- Registro e inicio de sesión de usuarios
- Validación básica de credenciales
- Persistencia de sesión (opcional en desarrollo)

---

### 🎥 2. Página Principal (Reconocimiento con cámara)

- Activación de la cámara del dispositivo
- Vista en tiempo real del usuario
- Interfaz preparada para integración futura con IA
- Mensaje o indicador de detección de señas (simulado)

⚠️ **Nota:** La funcionalidad de reconocimiento con inteligencia artificial **no está implementada todavía**, pero la interfaz está preparada como prototipo visual.

---

### 📚 3. Sección de Aprendizaje

- Tutoriales básicos del lenguaje de señas colombiano
- Contenido educativo estructurado:
  - Alfabeto
  - Saludos
  - Palabras comunes
- Ilustraciones/dibujos amigables
- Diseño enfocado en facilidad de aprendizaje

---

## 🎨 Diseño

- Interfaz amigable y accesible
- Estilo moderno y limpio
- Paleta de colores suaves e inclusiva
- Enfocado en experiencia de usuario (UX)

---

## 🛠️ Tecnologías

- Frontend: HTML5, CSS3, JavaScript
- Backend : Node.js, Express
- Otros: WebRTC para cámara, TensorFlow.js o MediaPipe (futuro)

---

## 🚧 Estado del Proyecto

✔ Login básico

✔ Sección de aprendizaje
